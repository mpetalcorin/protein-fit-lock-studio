
# Protein Fit Lock Studio

Protein Fit Lock Studio is a local scientific web app for estimating whether two protein chains fit together well, like a key fitting into a lock.

It accepts PDB or mmCIF structures, detects chains, calculates interface contacts, estimates geometric complementarity, detects steric clashes, and gives a layman-friendly interpretation of the protein-protein interface.

This is an educational and prototyping implementation. For publication-grade structural biology, validate with established tools such as SC, sc-rs, PyMOL, ChimeraX, FreeSASA, Rosetta, HADDOCK, or molecular dynamics workflows.
