# Portfolio Summary: Protein Fit Lock Studio

Protein Fit Lock Studio is a computational structural biology application for analysing whether two protein chains fit together well, like a molecular key fitting into a lock.

The project combines a Python FastAPI backend with a React frontend and interactive 3D molecular visualisation. It accepts PDB and mmCIF files, detects chains, calculates interface contacts, estimates shape-complementarity-like fit, detects clash-like contacts, identifies salt-bridge-like and hydrogen-bond-like interactions, ranks residue hotspots, and produces design recommendations.

The application is relevant to antibody engineering, protein binder design, docking triage, structural biology education, and early-stage biologics discovery. It demonstrates practical skills in scientific software engineering, molecular data parsing, numerical analysis, API design, frontend visualisation, Docker deployment, and reproducible research workflows.

Key capabilities include:

- Protein structure upload and parsing.
- Chain-pair selection and batch chain-pair ranking.
- Interface contact and clash analysis.
- Approximate shape-complementarity-like scoring.
- Hydrogen-bond-like, salt-bridge-like, aromatic, and hydrophobic contact summaries.
- Designability scoring.
- Mutation and redesign suggestion engine.
- 3D molecular viewer integration.
- JSON, CSV, and HTML report export.
- Dockerised deployment.
- Automated backend tests and frontend build validation.

This project is designed as a strong portfolio example for roles in computational biology, biologics engineering, antibody discovery, structural bioinformatics, AI-enabled drug discovery, and scientific software development.
